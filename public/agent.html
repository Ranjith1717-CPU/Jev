Try a customer

Jev runs the agent loop.

A support agent for a food delivery app. At every step Jev reads the customer message and the tool results so far, and picks the next tool, until it replies, asks or escalates. The tools are mocks over five fake orders (A1042, A1038, A0991, A1040, A1077); the reply is a template. Jev decides every step; it does not write text.

Jev plays the Dino game.

Every move is a live Jev decision: jump, duck or keep running. The game only describes what is happening. Jev decides.

Press Space or ↑ (or click the game) to jump, hold ↓ to duck. Jev watches and shows what it would do.

Each answer takes about 0.6 s round trip, so the game keeps several questions in flight at once, each about what the dino will face when the answer lands. Jev reads the game as text, not pixels. Birds start showing up after the first 8 obstacles.

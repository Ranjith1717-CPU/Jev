Jev demos

Small apps showing what TypeSafe's Jev model is for: fast, typed, structured decisions — not generated text. Every page shows the real request and response.

Server has no TYPESAFE_API_KEY set yet — the demos will error until you add one to .env. See the setup note below.

Agent decisions & tool calling

Tool router

The first step of every agent turn: which tool to call, and whether to ask a follow-up, wait for confirmation or just go. Bring your own tool list; Jev gives a probability for every tool.

/tools

Tool-call guardrail

Before an agent's tool call runs, Jev checks it against what the user asked: off task, destructive, leaking secrets, or following instructions planted in a web page. Allow, ask or block.

/guard

Jev runs the agent loop

A support agent with seven tools. Every step (look up, track, check policy, refund, reply, escalate) is a Jev decision, with a built-in guard against planted instructions.

/agent

Help-desk triage

Write a customer complaint. One call, eight parallel questions decide whether the agent acts on its own, a person confirms, or a person takes over.

/send

Classification & real-time control

Smart paste

Copy a whole résumé once. Paste into any form field. Jev picks the exact snippet that belongs there.

/paste

Jev plays Flappy Bird

Every move — flap or wait — is a live Jev decision. The game only describes what's happening in text; Jev decides.

/flappy

Jev plays the Dino game

The Chrome T-Rex runner: every move — jump, duck or keep running — is a live Jev decision, made from a text description of the cactus or bird ahead.

/dino

Sort an inbox

Jev classifies 1,000 real Enron emails live (spam, priority, category, reply-needed) — or connect your own Gmail, read-only, subject lines only.

/mail
Server setup: copy .env.example to .env, add your TYPESAFE_API_KEY from console.typesafe.ai/keys, then npm install && npm start. Gmail is optional — see README.md.

Jev plays Flappy Bird.

Every move is a live Jev decision: flap or wait. The game only describes what is happening. Jev decides.

Each answer takes about 0.6 s round trip (Jev thinks for about 0.3 s), so the game keeps several questions in flight at once, each about where the bird will be when the answer lands. Jev reads the game as text, not pixels.
